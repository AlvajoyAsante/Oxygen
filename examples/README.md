# Examples

* Cursor
  - Shows you how to setup and use the cursor.

* Demos
  - Click a box: A simple demo that shows you how the cursor works.
  - Flip Frog: A simple frog demo displaying how the cursor and other pre-alpha items work.
  - Simon Says: A simple color game that uses Oxygen to show the many features that it provides.

* GUI
  - Shows you how to use and setup different GUI functions.

* Widgets
  - Widget showcase: A small example that demonstrates buttons, checkboxes, switches, and labels using Oxygen widgets.
